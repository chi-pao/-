公開用パッケージ（秘密情報・研究用データ・巨大モデルは含みません）

1. GitHubの既存 main を直接上書きせず、まず新しいブランチ public-test を作成してください。
2. ZIPを解凍し、中身をGitHubの public-test ブランチにアップロードします。フォルダ assets も必要です。
3. Streamlit Community Cloudでテスト用アプリを public-test / app.py から新規作成し、動作確認します。
4. MLIT_API_KEY はStreamlitのSecretsに設定します。秘密キーをGitHubへアップロードしないでください。
5. 画面・3種類の査定・モデルの初回取得が正常に動いた後、mainにマージして本番へ反映します。

注意: このセットは初回モデル取得を実装していますが、公開環境での実動作検証は未実施です。自動研究の結果を本番に自動採用する機能は含みません。
